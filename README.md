# 有序 · 任务管理

课堂实践项目，使用 Vue 3、Vite、Tailwind CSS 和 localStorage 实现浏览器端任务管理。

## 运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可。生产构建使用 `npm run build`，单元测试使用 `npm test`。

## 课堂演示流程

1. 点击“新建任务”，展示标题必填、描述、状态和优先级。
2. 创建任务后切换“看板”，将卡片拖到“进行中”或“完成”。
3. 回到“列表”，打开详情并编辑任务，演示两种视图数据同步。
4. 切换深色模式并刷新页面，展示主题和任务均保留。
5. 点击删除，先取消，再次确认删除，展示删除确认流程。
